# ADHD 세계선수권 v0.4.2 — 앱인토스 WebView 게임

처음부터 회피·색상·생명선·기억·알림을 동시에 처리하고, 마지막 8초에는 아무것도 누르지 않는 70초 멀티태스킹 점수 경쟁 게임이다.



## v0.4.2 기억 임무 일시정지 수정

- 연습 모드뿐 아니라 실제 70초 경기의 모든 기억 문제에서 경기 전체 정지
- 기억 문제 동안 남은 시간·장애물·생명선·알림·무입력 판정·점수/콤보 변화 정지
- 답을 선택한 직후 프레임 시간과 무입력 기준 시간을 초기화하고 정상 재개
- 소스와 `preview-web` 빌드가 달랐던 문제를 제거하고 출시 번들 검증 명령 추가
- 검증 명령: `npm run verify:release`

## v0.4.1 최종 후보 수정

- 첫 화면 설명을 의도한 두 줄로 고정
- 기억 임무가 열린 동안 경기 전체 일시정지
- 기억 임무 답변 후 타이머·장애물·생명선 정상 재개
- 기억 임무 배경을 불투명하게 강화하고 재개 안내 문구 추가

## v0.4 핵심 변경

- 한국어 제목을 작게 조정하고 단어 중간 줄바꿈 방지
- 튜토리얼 카드의 과도한 빈 공간 축소
- 일반 경기마다 기억 패턴을 새로운 랜덤 시드로 생성
- 시작 즉시 모든 임무 활성화
- 시간이 지날수록 속도만 아니라 규칙과 동시 처리 복잡도 상승
- 혼란 3단계부터 좌우 반전 규칙을 예고 후 적용
- 색상 버튼 위치 셔플, 복합 장애물, 이동하는 알림, 기억 길이 4→5→6

## 난이도 구조

| 구간 | 전체 임무 | 추가 변화 |
|---|---|---|
| 1단계 | 전부 활성화 | 장애물 1개, 색상 위치 고정, 기억 4개 |
| 2단계 | 전부 유지 | 색상 버튼 위치 셔플, 장애물 2개 가능 |
| 3단계 | 전부 유지 | 기억 5개, 좌우 반전 규칙, 알림 응답시간 단축 |
| 4단계 | 전부 유지 | 기억 6개, 복합 장애물 빈도 상승, 알림 위치 이동, 좌우 반전 주기 단축 |
| 최종 보스 | 기존 임무 정지 | 마지막 8초 동안 아무것도 누르지 않기 |

## 조작

- 모바일: 회피 구역 왼쪽·오른쪽 터치 또는 좌우 스와이프
- PC: 방향키 `←` `→` 또는 `A` `D`
- 색상: 화면에 적힌 색 이름과 같은 하단 색 버튼
- 생명선: 82% 이하에서만 충전
- 알림: 긴급 알림만 누르고 무료 점수 알림은 무시
- 기억: 경기 중 표시된 기호 순서를 나중에 선택
- 마지막 8초: 화면에서 손을 떼기

## 바로 미리보기

```bash
bash scripts/run_preview.sh
```

브라우저에서 `http://localhost:8080`을 연다. ZIP 안의 `preview-web/`은 빌드 완료된 정적 버전이다.

## 개발 및 자동 검사

Node.js 24 이상 권장.

```bash
npm install
npm run typecheck
npm test
npm run build:web
npm run qa
```

`npm run qa`는 설치된 Google Chrome을 우선 사용하고, 없을 때만 Playwright Chromium을 설치한다. 화면을 보면서 실행하려면:

```bash
npm run qa:headed
```

## 앱인토스 업로드 전 수정

`granite.config.ts`에서 콘솔 값으로 바꾼다.

```ts
appName: '콘솔에서 만든 실제 appName',
brand: {
  displayName: '콘솔에 등록한 표시 이름',
  primaryColor: '#B6FF39',
  icon: '콘솔에 업로드한 실제 아이콘 URL',
}
```

그다음:

```bash
npm run build
```

생성된 `.ait`를 앱인토스 콘솔 테스트 단계에 업로드한다.

## 출시 전 최종 확인

- `npm run qa` 전체 PASS
- 375×667, 390×844 실기기 화면 확인
- 정상 플레이로 혼란 4단계와 보스 진입 가능 여부
- 기억 패턴이 재도전마다 달라지는지 확인
- 좌우 반전 예고 문구와 실제 조작 일치 여부
- 앱인토스 실제 `appName`, 아이콘 URL 반영
- 리더보드 콘솔 설정 및 샌드박스 점수 제출 확인
- 게임 등급분류 자료 준비

## 주의

이 게임은 ADHD를 진단하거나 치료하는 프로그램이 아니라 멀티태스킹 캐주얼 게임이다.
